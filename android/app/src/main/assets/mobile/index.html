    How it works
    Hold SOXL by default. When a 1h bar closes with ADMF red on SOXS or on SOXL, go to cash for the next 4 bars (a new red restarts the count). If SOXL turns aqua or SOXS turns orange during that time, buy back early. The call uses the last finished 1h bar; act on it at the next bar's open. Uses the ADMF defaults (length 14, lookback 20): other settings test noticeably worse.

      Phone alerts SOXL ADMF Pivot
        How the alerts work
        The phone checks about 2 minutes after each 1h bar closes on weekdays (10:32, 11:32 … 15:32 and 16:02 New York time), and again every 2 minutes until Yahoo has that bar. It works with the app closed and the screen off. Each alert says which bar triggered it, why, and when to act (at the next bar's open, or at the 9:30 open for a signal from the day's last bar). If the phone was off when the call changed, the alert arrives when it's back on, with the bar time so you can tell it's late. Nothing places orders.

        For on-time alerts, allow notifications, keep exact timing on and set battery use to Unrestricted: some phones (Samsung, Xiaomi, OnePlus…) otherwise delay or skip background checks.
